# 🤖 Bot de Discord con IA

Bot de Discord hecho con Python y discord.py. Proyecto de práctica de bots, integración con IA y uso de Git/GitHub.

## Funciones

- `/hola` → el bot te saluda
- `/dado` → tira un dado del 1 al 6
- `/info` → información sobre el bot
- `/menu` → muestra un menú con botones interactivos
- `/chat` → hacele una pregunta a la IA (conectado con Gemini)
- Mensaje de bienvenida automático cuando alguien se une al servidor

## Tecnologías

- Python
- discord.py
- google-genai (API de Gemini)
- python-dotenv

markdown
## Cómo correrlo

1. Cloná el repositorio
2. Instalá las dependencias:

pip install discord.py python-dotenv google-genai

3. Creá un archivo `.env` con:

DISCORD_TOKEN=tu_token_aca
GEMINI_API_KEY=tu_clave_aca

4. Corré:

python bot.py
